# Changelog

## 2.0.0 — Full-Stack Portfolio Upgrade

- Migrated the original static storefront into Laravel Blade views.
- Added categories/products backed by Eloquent.
- Added search, filters, sorting, persistent cart and wishlist.
- Added normalized orders/order items and customer order history.
- Added transactional checkout, row locking and stock restoration on cancellation.
- Added role-based Admin dashboard and catalog/order management.
- Added soft-delete product archive/restore.
- Added contact-message persistence and Admin inbox.
- Added seeded demo catalog, feature tests, CI and Dependabot.
- Replaced generic project documentation with portfolio-focused documentation.
